# Security Policy

## About
This repository hosts the source code for the Sankalp Computer Classes website, a static site hosted on GitHub Pages.

## Supported Versions
Only the latest version deployed from the `main` branch is maintained and receives security fixes.

| Branch | Supported |
| ------ | --------- |
| main   | ✅        |
| others | ❌        |

## Reporting a Vulnerability
If you discover a security issue with this website (e.g. exposed credentials, XSS, broken links leading to malicious content, or misconfigured hosting), please report it responsibly:

- **Email:** shivametawah@gmail.com
- Please do **not** open a public GitHub issue for security vulnerabilities — email first so it can be fixed before public disclosure.

When reporting, please include:
- A description of the issue
- Steps to reproduce (if applicable)
- Any relevant screenshots or URLs

## Response Time
We aim to acknowledge reports within 48–72 hours and resolve confirmed issues as quickly as possible.

## Scope
This policy covers the website's source code and deployment configuration in this repository. It does not cover third-party services linked from the site (e.g. payment gateways, external forms) — please report those directly to the respective provider.
